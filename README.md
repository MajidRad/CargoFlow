CargoFlow is a  logistics and delivery platform built with .NET, designed to explore and practice modern distributed system and software architecture concepts.

The project simulates an end-to-end delivery workflow, from order creation and inventory reservation to shipment creation and real-time delivery status updates.

### Key Concepts

* Domain-Driven Design (DDD)
* Event-Driven Architecture (EDA)
* Microservices
* RabbitMQ
* PostgreSQL
* SignalR for real-time communication
* Unit Testing
* Integration Testing
* Structured Logging with Serilog
* Elasticsearch, Logstash & Kibana (ELK)
* Docker & Docker Compose
* Correlation IDs and distributed request tracing

### Main Workflow

`Order → Inventory → Shipping → Notification → SignalR`
